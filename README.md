# BiotechHub

**A student-run platform for biotechnology students at TU Braunschweig.**

[**Visit BiotechHub**](https://biotechhub.eu)

## About the project

BiotechHub is an independent initiative by students for students of biotechnology at **Technische Universität Braunschweig**. Its goal is to make study-related resources and digital services accessible and maintainable over the long term.

The platform is operated as a student project and is not an official university service.

## What does BiotechHub offer?

- **Study resources:** A web-based portal for accessing learning materials.
- **File services:** A Nextcloud-based service supporting the platform's file management.
- **Continuity:** Documentation and a maintainable technical setup intended to make it easier for future student volunteers to keep the project running.

Access to specific materials or functions may depend on the respective permissions.

## Technology

BiotechHub currently uses a lightweight stack including:

- **Python and Flask** for the website
- **Nextcloud** for file services
- **Docker Compose**, **MariaDB** and **Redis** for supporting services
- **Cloudflare Tunnel** for public access

This is a high-level overview. Internal infrastructure, access credentials, backup procedures and operational details are deliberately kept in private documentation.

## Get involved

BiotechHub is intended to be developed and maintained across student generations. Students interested in contributing ideas, improving the platform or helping with its long-term operation are welcome to get in touch through the project and its student organizers.

This repository currently provides **public project information**, not the complete application source code. Publishing source code or opening external contributions may be considered separately in the future.
